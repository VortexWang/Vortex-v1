## 外部依赖

Agent 与 Edge Hub 按契约 C2 使用 gRPC（grpc-go、protobuf 运行时）与 SQLite。当前开发环境访问 Go 模块代理 `proxy.golang.org` 被网络策略拒绝（403）；已决定放行该代理（2026-11-01）。放行生效前先实现不依赖外部模块的部分：存储与传输抽象为接口，账本暂用 JSON 行文件（每次追加 fsync），放行后替换为 SQLite（WAL）与生成的 gRPC 代码，接口不变。
