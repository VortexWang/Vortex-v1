## CR-01 引擎接口 `DrainUsage` 的返回类型

| 项 | 内容 |
| --- | --- |
| 提出日期 | 2026-10-31 |
| 来源 | 实现 ENG-T01（引擎骨架）时发现 |
| 现状 | 需求 8.2 节代码块：`DrainUsage() []UsageDelta` |
| 问题 | 已锁定的契约 C2a（决定 D8）规定引擎输出为 `runtime.v1.UsageSnapshot`，除逐规则用量外还必须携带 LIM-009 的需求信号（令牌耗尽占比）与逐授权消费量（计费授权结算依据）。`[]UsageDelta` 无法承载后两者，需求与契约不一致 |
| 建议 | 8.2 节改为 `DrainUsage() UsageSnapshot // Agent 每秒拉取：用量、需求信号、授权消费` |
| 影响的需求 | 8.2 节、ENG-039、LIM-009 |
| 影响的验收项 | 无（不改变任何行为，只修正接口签名） |
| 当前处理 | 代码按契约实现（`engine/engine.go` 注释中已标注），变更评审通过后作为需求 V1.8 发布 |
